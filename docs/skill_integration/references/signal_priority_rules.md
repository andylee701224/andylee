# ATE PCB 訊號優先級與佈排規則

本文件定義了 V93K ATE PCB 設計中各類訊號的優先級權重與佈排策略。

## 訊號分類與權重

在自動佈排系統的成本函數中，不同訊號類型具有不同的權重，以確保關鍵訊號的完整性。

| 訊號類型 | 權重 (Weight) | 說明 |
| :--- | :--- | :--- |
| **RF 訊號** | 3.0 | 射頻訊號，對損耗與反射極度敏感，需最短路徑。 |
| **HSIO (高速數位)** | 3.0 | 高速序列 I/O（如 PAM4），需嚴格控制阻抗與長度匹配。 |
| **時鐘 (Clock)** | 2.0 | 系統時鐘，需避免串擾，保持波形完整。 |
| **特殊應用 IO** | 1.5 | 特定測試用途的 IO，具備中等敏感度。 |
| **GPIO** | 1.0 | 通用輸入輸出，對佈線長度要求較低。 |
| **電源 (Power)** | 1.0 | VDD/VSS，需確保低阻抗路徑，通常透過內層平面處理。 |

## 佈排策略與約束

### 1. RF 與 HSIO 訊號
- **位置約束**：相關元件必須放置於距離連接器或 DUT 最近的區域。
- **層間約束**：盡量避免過孔 (Via)，若必須使用，需進行背鑽 (Backdrill) 處理。
- **間距約束**：與其他訊號保持至少 3W（線寬的三倍）的間距，以減少串擾。

### 2. 時鐘訊號
- **拓撲結構**：採用菊花鏈 (Daisy Chain) 或星型 (Star) 拓撲佈線。
- **屏蔽要求**：兩側需有地線 (Ground Guard Trace) 屏蔽。
- **長度匹配**：差分對內長度誤差需小於 5 mil。

### 3. 電源與接地
- **去耦電容**：必須緊鄰 DUT 的電源引腳放置，距離越短越好。
- **平面分割**：不同電壓域需在內層進行合理的平面分割 (Split Plane)。
- **迴流路徑**：確保所有高速訊號下方有連續的參考平面，避免跨越分割區。

## 成本函數應用

在模擬退火與強化學習演算法中，總線長 (HPWL) 的計算公式為：

`Total_HPWL = Σ (Weight_i * HPWL_i)`

其中 `Weight_i` 為上述表格中定義的訊號權重，`HPWL_i` 為該網路的半周長線長。此設計確保演算法在優化過程中，會優先縮短高權重訊號的佈線距離。
