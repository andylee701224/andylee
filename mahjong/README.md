# 台灣麻將 (16 張) — Web 版

純前端 HTML/Canvas 實作的台灣麻將遊戲,單人對戰 3 個電腦 AI。風格參考「神來也」「明星三缺一」,規則為標準台灣 16 張,計分採神來也台數系統。

## 執行方式

由於 `index.html` 用 `<script src="...">` 載入,不能直接 `file://` 開(部分瀏覽器會擋),需要起個本地伺服器:

```bash
cd mahjong
python3 -m http.server 8080
# 瀏覽器開 http://localhost:8080/
```

或:
```bash
npx serve .
```

## 測試核心邏輯

```bash
cd mahjong
node tests/test_core.js
```

## 檔案結構

```
mahjong/
├── index.html
├── css/style.css
├── js/
│   ├── tiles.js     # 144 張牌的定義 (m萬/p筒/s索/z字/f花)
│   ├── win.js       # 胡牌判定 (5 面子 + 1 對的遞迴拆解) + 聽牌計算
│   ├── tai.js       # 台數計算 (神來也風格:平胡、碰碰胡、清一色、大三元、大四喜...)
│   ├── ai.js        # 規則式 AI (打牌、吃碰槓胡決策)
│   ├── game.js      # 遊戲狀態機 (洗牌、發牌、補花、輪轉、副露、流局)
│   ├── render.js    # Canvas 牌桌渲染 (程式繪牌面,無需圖檔)
│   └── main.js      # UI 互動、人類玩家事件、AI 排程
└── tests/test_core.js
```

## 實作的台型

- 基本:莊家、連N拉N、自摸、門清、門清自摸
- 牌型:平胡、碰碰胡、混一色、清一色、字一色
- 三元:大三元、小三元、單組三元
- 四喜:大四喜、小四喜
- 風牌:圈風、門風
- 槓:明槓、暗槓
- 特殊:天胡、地胡、槓上開花、海底撈月、搶槓胡、花胡
- 花牌:每張 1 台、正花、八仙過海

## 已知限制 (MVP)

- 吃只會自動選第一個組合(未提供吃法選擇 UI)
- 棄牌後若人類玩家 pass,後續 AI 的同時宣告未完整處理
- 沒有連線多人模式
- 沒有牌效計算助手(教學模式)
- 計分為固定 10 分/台(可在 `main.js` `perTai` 調整)
